# NFT Staking Core

An NFT staking program built with Anchor on Solana, using Metaplex Core assets.

## Features

- Initialize a staking collection with a reward mint
- Stake and unstake NFTs
- Claim staking rewards
- Burn staked NFTs

## Tech Stack

- [Anchor](https://www.anchor-lang.com/) 0.31.1
- [Metaplex Core](https://developers.metaplex.com/core) 1.10.0
- Solana 3.1.10

## Getting Started

### Prerequisites

- [Rust](https://www.rust-lang.org/tools/install)
- [Solana CLI](https://docs.solana.com/cli/install-solana-cli-tools)
- [Anchor](https://www.anchor-lang.com/docs/installation)
- [Yarn](https://yarnpkg.com/)

### Install

```bash
yarn install
```

### Build

```bash
anchor build
```

### Test

```bash
anchor test
```
